## 这是什么

单文件文字修仙游戏《问道 · 文字轮回》。零依赖、零构建，双击 HTML 就能玩。
所有代码（HTML + CSS + JS）都在一个文件里，没有 package.json，没有框架。

## 文件

- `text-rpg.html` —— 游戏本体，全部内容，约 2600 行 / 135 KB。
- `README.md` —— 项目说明、目录、提交规范。
- `CHANGELOG.md` —— 各版本改动记录，写新功能时同步补一条。
- `一键提交.bat` —— 双击提交并推送，可输入一句说明。
- `docs/开发状态.md` —— 本文件。
- `.workbuddy/memory/YYYY-MM-DD.md` —— 按日期的开发日志，只追加不改写。

## 架构（照着这个分层改，不要横着插代码）

| 层 | 关键函数 / 数据 | 说明 |
|---|---|---|
| 资料 | `WORLDS`(12) `LANDS`(16) `BIRTHS`(16) `TALENTS`(14) `MARKS`(14) `ITEMS` `ENEMIES`(6) `REALMS` / `REALM_EXP` / `REALM_LINE` | 纯数据表，改内容只动这里 |
| 开局 | `rollSpec()` → `buildState(spec)` | 先掷纯数据「设定」，再派生完整状态。`S.spec` 挂在状态上，支撑单项重掷 |
| 场景 | `SCENE_FIND / FORTUNE / TRADE / NPC / OMEN / CRISIS / ROAD` + `LAND_POOL` | 每个选项自带 `out` 结算函数；`LAND_POOL` 按地形改权重 |
| 章节 | `ANCHORS`（第 6/14/22/32/42 回） | 五章主线：引路 → 一口气 → 山门之外 → 拦路的人 → 鸣；第 50 回收束 |
| 状态引擎 | `applyOps()` | 白名单 ops：hp / mp / exp / money / item / drop / buff / attr / flag / move / equip / heal |
| 战斗 | `combatTurn()` → `enemyTurn()` | `INTENTS` 意图预告、守势、看破加成、`foeRead()` 用真实数值反推胜负 |
| 存档 | `saveRun()` / `loadRun()` / `rehydrate()` | localStorage `wd_run`，v2；`render()` 末尾自动存 |
| 行路 | `travelTo()` / `renderMap()` / `rollRoutes()` / `dayFor()` | 右侧「天下」面板，走一处耗一回 |
| AI 通道（可选） | `LLM` / `aiPrompt()` / `llmTurn()` | OpenAI 兼容 `/chat/completions` + `json_object`，配置存 `wd_llm` |

## 已完成的四轮

1. **原型**：本地导演引擎 + 状态引擎 + 可选真 AI 通道。（v0.1.0）
2. **随机开局**：世道 × 地界 × 身世 × 天赋 × 隐患，约 22 万种组合，每项可单独重掷。隐患真的会咬人（掉血 / 增遇敌 / 减逃跑 / 扣灵石）。（v0.2.0）
3. **装备与遭遇**：兵器 / 护体 / 佩物三槽、遭遇卡（类别 / 兵器 / 修为 / 估量）、敏捷生效（逃跑 + 闪避）。（v0.3.0）
4. **行路 + 存档 + 战斗战术**：16 个地界可走、自动存档续玩、对手意图预告、守势换灵力、看破后增伤。（v0.4.0）

## 待办

1. **云端存档** —— 目前存档只在浏览器本地，换设备不同步。要跨设备得加登录 + 一张 `saves` 表。
2. **地标事件** —— 每个地界还只有一个 `t` 见闻句，缺专属事件；这是让「行路」变厚的最短路径。
3. **轮回累积** —— `S.deaths` 目前只用来数「第 N 世」，可以接天赋继承或前世因果。
4. **结局分支** —— 第 50 回固定一个结局，可以按 `flags` 分裂成几种。
5. **手机真机** —— 窄屏逻辑写过（820px 断点），但没在真机上验过。

## 怎么验证改动

无依赖，两种方式：

```bash
# 1. 语法检查
node -e "const fs=require('fs');const h=fs.readFileSync('text-rpg.html','utf8');fs.writeFileSync('/tmp/c.js',h.match(/<script>([\s\S]*)<\/script>/)[1])" && node --check /tmp/c.js

# 2. 直接开浏览器
start text-rpg.html
```

改完后至少手动走一遍：开局卷 → 掷一次 → 开始 → 走 10 回（含一次战斗、一次行路）→ 刷新页面看「未完」能不能续上。

## 文风与约束（改文案前必读）

- 中文，第二人称，冷峻克制，短句。不解释规则，不写「你获得了 3 点经验」这类系统腔。
- 不用 emoji，不用感叹号堆情绪，不写元叙事（不出现「第 N 章」以外的编号说明）。
- 描写要经得起推敲：半日劳作不会长出老茧，伤口的干法对应真实时辰。
- 数值必须自洽：气血上限 = 78 + 力×3 + 突破所得；灵力上限 = 12 + 悟×3 + 佩物。
