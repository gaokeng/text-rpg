# 问道 · 文字轮回

一个单文件的文字修仙游戏。掷一次人物，走进一个乱世，五十回收束。

零依赖、零构建、零后端——所有 HTML / CSS / JavaScript 都在一个文件里，双击就能玩。

## 怎么玩

直接双击 `text-rpg.html`，会用浏览器打开。

开局先掷一次人物：世道、地界、身世、天赋、隐患各自独立，任何一项不满意都能单独重掷。你叫什么是自己定的。

之后是一场五十回的旅程。每回有若干选项，也可以自己输入想做的事。左侧是正文，右侧是属性、行囊、当前对手和「天下」——地图上能走的三个方向。

游戏自动存档，刷新页面能看到「未完 · 第 N 回」的续玩入口。

## 开发方式

这个项目是**和 AI 结对**写出来的，不是手敲的。所以仓库里最值钱的东西不是代码，是 `docs/开发状态.md` —— 它记录了九层架构的划分、已经踩过的坑、以及不能违反的数值约束。

接手开发时先读它，能省掉重新摸 2600 行的功夫。

代码分九层，改功能时按层归位，不要横着插：

| 层 | 职责 |
|---|---|
| 资料 | `WORLDS` / `LANDS` / `BIRTHS` / `TALENTS` / `MARKS` / `ITEMS` / `ENEMIES` 等纯数据表 |
| 开局 | `rollSpec()` 掷设定 → `buildState(spec)` 派生状态 |
| 场景 | `SCENE_*` 各类场景，每个选项自带结算函数 |
| 章节 | `ANCHORS` 五个主线节点 |
| 状态引擎 | `applyOps()` 白名单指令，所有数值改动必经此地 |
| 战斗 | `combatTurn()` / `enemyTurn()`，含意图预告与守势 |
| 存档 | `saveRun()` / `loadRun()` / `rehydrate()` |
| 行路 | `travelTo()` / `renderMap()` / `rollRoutes()` |
| AI 通道 | `LLM` / `aiTurn()`，可选，接 OpenAI 兼容接口 |

细节见 [docs/开发状态.md](docs/开发状态.md)。

## 提交规范

提交信息写清楚「改了什么」，别用「update」「修改一下」这类话——三个月后你自己也看不懂。

```
feat: 增加了什么功能
fix: 修了什么 bug
docs: 只改文档
refactor: 不改行为的代码整理
chore: 配置、脚本之类
```

日常流程：改完 → 双击 `一键提交.bat` → 输入一句话说明。脚本会暂存、提交、推送。

换电脑时：

```bash
git clone https://github.com/gaokeng/text-rpg.git
```

整个项目连同全部历史一起到位，然后读 `docs/开发状态.md` 接着做。
